# CineClaw AI Engine (`cineclaw-ai`)

Специализированный микросервис искусственного интеллекта в экосистеме CineClaw на Go 1.25.

## Возможности
- **Оценки критиков**: агрегация рейтингов Rotten Tomatoes %, Metacritic Metascore, IMDb и наград через OMDb API.
- **Тексты рецензий**: сбор отзывов зрителей и прессы через TMDB Reviews API.
- **AI-Консенсус**: синтез структурированной выжимки (вердикт, плюсы, минусы, кому смотреть) через OpenRouter (`google/gemini-2.5-flash`).
- **Персистентный кэш**: встраиваемая БД `bbolt` (`ai_store.db`), мгновенный повторный ответ за 0 мс и $0.
- **Отказоустойчивость**: graceful fallback при отсутствии API-ключей без прерывания работы.

## Запуск
```bash
go run ./cmd/server
```

## Эндпоинты
- `GET /health` — проверка работоспособности.
- `GET /api/critics/:tconst` — получение оценок критиков и AI-консенсуса по IMDb ID фильма.
